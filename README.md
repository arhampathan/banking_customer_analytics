# banking_customer_analytics
📌 Project Overview

This project focuses on analyzing 3000 banking customers using Python for Exploratory Data Analysis (EDA) and Power BI for interactive dashboard development.

The objective was to understand customer financial behavior, loan exposure, deposit trends, and risk distribution — and translate raw data into meaningful business insights.

Dataset Size:

3000 Customers

25 Features (Demographic + Financial Attributes)

🎯 Project Objectives

Perform detailed Exploratory Data Analysis (EDA)

Segment customers based on income levels

Analyze loan and deposit distribution

Identify correlations between financial variables

Build an interactive multi-page Power BI dashboard

📊 Exploratory Data Analysis (Python)

Performed using:

Pandas

NumPy

Matplotlib

Seaborn

Key Findings:

1️⃣ Income Segmentation

Customers were categorized into:

Low Income

Medium Income

High Income

Majority of customers fall under the Medium Income Band, indicating strong mid-market concentration.

2️⃣ Credit Behavior

Most customers hold 1 credit card

Smaller percentage hold 2–3 cards

This suggests potential for credit card upselling strategies.

3️⃣ Risk Distribution

Majority customers fall under Risk Weighting 1–2

Indicates a relatively stable and low-to-moderate risk portfolio

4️⃣ Correlation Analysis

Strong positive correlation found between:

Bank Deposits

Checking Accounts

Saving Accounts

Foreign Currency Accounts

Insight: Customers maintaining high balances in one account type often hold funds across multiple account types, indicating cross-product engagement.
